# CanvasHelper

A desktop assignment tracker built with Python to fetch upcoming assignments from the Canvas LMS API.

---

## Features

* **Automated Sync:** Pulls active courses and upcoming assignment deadlines automatically.
* **Custom Desktop UI:** Clean visual display powered by CustomTkinter.
* **Secure Environment:** Keeps API credentials safe using local `.env` configuration.

---

## Getting Started

### 1. Prerequisites
Make sure you have Python installed, then clone the repository. Run "pip install -r requirements.txt" to install dependencies.

### 2. .env File
Create a .env file inside CanvasNotiHelper/ with your unique Canvas token and URL

Example of .env contents:

    CANVAS_URL = your_url_here ~~ https://canvas.instructure.com
    CANVAS_TOKEN = your_token_here
